# Touchless Spotify Controller

A Python project that aims to control Spotify playback and volume using hand gestures captured through a webcam.

## Planned Controls

* Play/Pause
* Next track
* Previous track
* Volume up
* Volume down
* Mute/Unmute

## Tech Stack

* Python
* OpenCV
* MediaPipe
* NumPy
* Spotipy (Spotify Web API)

## Project Status

Currently setting up the development environment and testing webcam access.
